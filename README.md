## Technical & Informatics Core Competencies

* **Interoperability & Data Standards:** HL7 FHIR (Fast Healthcare Interoperability Resources) R4, JSON data modeling, SMART on FHIR architecture, LOINC, SNOMED CT, ICD-10.
* **Database & Clinical Analytics:** SQL (Complex filtering, window functions, aggregations, relational integrity), Electronic Health Record (EHR) database structures.
* **Systems & Strategic Consulting:** Health system workflow bottleneck analysis, care transition mapping, rural health outmigration assessments, enterprise clinical software evaluation.
* **Applied Health Research:** Systematic review synthesis, PRISMA flow methodologies, predictive model evaluation metrics (precision, recall, AUC-ROC) in chronic disease cohorts.
